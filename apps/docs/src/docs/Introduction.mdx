# GovBB Design System

The single source of truth for the design guidelines, constraints, and standards
that govern official Government of Barbados websites.

> **Placeholder home page.** This scaffold (issue #113) stands up the docs site so
> content and component-reference work can build on it. The pages below are stubs.

## What lives here

- **Guidelines** — visual language, layout, accessibility, tone and content standards.
- **Constraints** — what official GoB sites must and must not do.
- **Standards** — component specifications and design tokens.
- **Components** — live examples and usage code for each component in the system.

## Where to start

- New to the system? See **Guidelines → Getting Started**.
- Looking for a component? Browse the **Components** section in the sidebar.
