## Adopting the design system

1. Install the component library (coming soon — tracked separately).
2. Import the GovBB design tokens so your site inherits the official branding.
3. Use components from the **Components** section, following each component's usage rules.

## Principles

- **Accessible by default** — every component is audited against WCAG (see the
  accessibility audit issues #87–#109).
- **Consistent branding** — colour, typography, and spacing come from shared tokens.
- **Government-appropriate** — clear, plain language and predictable patterns.
