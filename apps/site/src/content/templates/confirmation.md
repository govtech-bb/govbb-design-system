The confirmation page is the last step of a service. Make it unmistakably a
success, show a reference number the user can keep, and tell them what happens
next so they are not left wondering whether it worked. Like every page of a
service, the template keeps the standard
[official banner](/components/official-banner/), [header](/components/header/)
and [footer](/components/footer/).

## The reference number

Give every completed transaction a reference the user can quote if they contact
you. Show it prominently and repeat it in the confirmation email.

## What happens next

Set expectations: what you will do, roughly when, and whether the user needs to
do anything. If there is a follow-up action, link to it here.

## Do not rely on this page alone

Users close tabs and lose pages. Send the same confirmation and reference by
email, and do not put anything on this page that exists nowhere else.
