# GovBB component workshop

This Storybook is the interactive workshop for developing and reviewing the
React API of the GovBB Design System in isolation.

The components render the same stable `govbb-*` classes and use the same
compiled stylesheet as the framework-agnostic `@govtech-bb/frontend` package.
The guidance, HTML examples, patterns, and design decisions continue to live in
the Astro documentation site. Storybook is published at `/storybook/` as its
interactive React companion.

Use stories to review component variants, difficult states, interactions, and
automated accessibility results. A story is development evidence, not a
replacement for testing a component in a complete service journey.
